        气象预警

        URL 模板变量：{city} {lat} {lon} {key}。 字段映射只接受 JSON（不执行任何代码）：值写成 "a.b[0].c" 路径，或 { "path": "...", "mul": 3.6, "add": -273.15, "map": {…}, "default": … }。 顶层可写 codes:"wmo"|"owm"（按天气代码补中文描述与图标）、units:{temp:"C"|"K",wind:"kmh"|"ms"}（自动归一到 °C 与 km/h）。 对象数组与 Open-Meteo 那种平行数组都支持：路径先按数组元素解析，取不到再回到根对象，命中数组时按行号取值。
